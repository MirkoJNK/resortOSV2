## Dependency lockfile — IMPORTANT

`package-lock.json` is **not included** because npm registry DNS failed (`EAI_AGAIN`) and the local npm cache was empty (`ENOTCACHED`). A lockfile must be generated **by npm itself** on a network-connected computer with `npm install` before the first commit for reproducible `npm ci` builds. The workflow can bootstrap with `npm install` without a lockfile, then will use `npm ci` once one is committed. **Do not invent or handwrite a lockfile.**
