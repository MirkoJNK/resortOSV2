# Visual Evidence

The `qa-evidence/focus-logo/` folder contains a side-by-side previous/refined vector logo comparison, an enlarged corrected logo, a desktop and mobile brand-loader fixture, and a focus CSS fixture at desktop/mobile sizes.

**Source distinction:** these are true vector rendering and Chromium browser CSS fixture screenshots. They do not represent screenshots of the complete React/Vite app, because runtime dependencies were unavailable. The app must still be visually checked locally after `npm install`.
