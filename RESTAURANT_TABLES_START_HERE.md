# Restaurant Tables — Start Here

This is the complete original resortOS React application with the **Restaurant → Tables** production integration candidate. It is **not** the Stage 3 prototype ZIP and does not use the prototype iframe.

1. Open a terminal in `resortOS_v0661_1_hotfix/`.
2. Run `npm ci`, then `npm run check:full` and `npm run format:typescript:check`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Switch to **Restaurant** and choose **Tables**.
5. Review the three tabs and the table-selected ordering/reservations workflows; source configuration is maintained in Admin Tables Manager.

See `RESTAURANT_TABLES_CHANGELOG.md`, `RESTAURANT_TABLES_CHANGED_FILES.md`, `RESTAURANT_TABLES_SQA_REPORT.md`, `RESTAURANT_TABLES_KNOWN_LIMITATIONS.md`, and `RESTAURANT_TABLES_PRODUCTION_INTEGRITY.json`.

The original project and catalogs are not silently reset. Never use demo browser-storage behavior as proof of shared resort production capabilities. No changes were pushed to GitHub.
