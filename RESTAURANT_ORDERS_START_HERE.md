# Restaurant Orders — start here

1. Extract the entire archive.
2. Open `resortOS_v0661_1_hotfix/` as the project root.
3. Install dependencies from the existing lockfile: `npm ci`.
4. Run `npm run check:full`.
5. Run `npm run dev`, then open Restaurant → Tables and create/record an order.
6. Mark Ready to Pay, click Payment and confirm a **Demo** Cash or Charge to Room transaction.
7. Open Restaurant → Orders. Verify the order in Order History and review its dedicated Details page.

Do not use this candidate for real financial collection. No GitHub push was performed.
